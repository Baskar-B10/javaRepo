# ☕ Java Skills Practice Repository

This repository contains a wide range of **Java practice programs, coding exercises, and concept implementations**. It is designed to strengthen core Java fundamentals, problem-solving skills, and advanced Java concepts through hands-on coding.

## 📚 Overview

The project covers:

* 🧠 Core Java fundamentals
* 📦 Collections Framework
* ⚡ Functional programming (Lambdas, Streams)
* 🕒 Date & Time API
* 🔁 Algorithms & problem-solving
* 🧵 Multithreading basics
* 📁 File handling
* ❗ Exception handling
* 🧪 Coding interview practice problems
